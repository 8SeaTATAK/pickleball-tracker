# 匹克球助手（微信小程序）

面向俱乐部运营的匹克球小程序：建俱乐部、发活动报名、自动排轮转对阵、录比分、积分榜，以及一套**模拟 DUPR** 的双打/单打评分。

原生微信小程序 + 微信云开发（云函数 + 云数据库），不需要自己的服务器。

## 功能

| 模块 | 内容 |
|---|---|
| 俱乐部 | 创建/编辑、邀请码加入、分享卡片加入、成员列表（按评分排序）、创建者设管理员、移出成员、退出 |
| 临时球员 | 管理员登记不用小程序的球友，可设起始水平，照样参与对阵、积分和评分 |
| 活动 | 发布（时间、地点、场地数、人数上限、费用、备注）、报名/取消、满员自动候补、取消后候补自动递补、管理员代报名、结束/重开/删除 |
| 对阵 | 5 种模式：双打轮转、双打均衡（按评分配平）、固定搭档循环、单打轮转、单打循环；可重新生成（已完赛保留）、手动加局 |
| 计分 | 本场球员或管理员录分，显示评分预测比分；录分后立刻显示每人评分变化；管理员可改分/删局（自动回滚评分） |
| 积分榜 | 俱乐部近 7 天 / 30 天 / 全部；本场排名；积分规则（胜/负各得几分）可配置 |
| 评分 | 2.000–8.000，双打单打分开，可靠度、暂定标记、评分走势图、最近比赛及每场评分变化 |
| 多语言 | 中文 / English / Tiếng Việt / Bahasa Melayu，默认跟随微信语言，「我的」页可切换；日期按语言显示（中文 11/23，其他 23/11）；活动费用币种可在俱乐部设置里选（A$ / ¥ / RM / S$ / ₫ / $） |

## 评分算法（模拟 DUPR）

DUPR 官方公式未公开。这里依据它公开的原则（看比分而非只看输赢、双打用队伍平均分、新球员波动大）做了 Elo 式近似：

```
期望得分率 E = 1 / (1 + 10^(-(本队评分 - 对手评分) / 2.8))
实际得分率 A = 本队得分 / 总得分
评分变化   Δ = K × 局长系数 × (A − E)

K       = 0.50 → 0.12，随场次线性降低（20 场可靠度 100%）
局长系数 = 总得分 / 18，限制在 0.5–1.25
```

评分差 1.0 时期望得分率约 69%，即预测 11:5。强队险胜可能掉分、弱队惜败可能涨分。
测试里有一个 1500 场的模拟：8 名真实水平 2.6–5.0 的球员从 3.5 起步，最终评分都收敛到真实水平 ±0.6 以内，首尾排序正确。

参数都在 `cloudfunctions/api/lib/rating.js` 顶部，可以按俱乐部实际情况调。

## 多语言

- 所有界面文字在 `miniprogram/utils/i18n.js`，每条是 `[中文, English, Tiếng Việt, Bahasa Melayu]`。改文案、加语言都只改这一个文件。
- 云函数只返回错误代码（如 `needAdmin`、`intRange`），由前端按用户语言翻译（词典里 `err_*` 条目）。
- 俱乐部名称、简介、昵称等用户填写的内容不翻译，原样显示。
- **越南语和马来语是初稿**，建议请会这两种语言的球友看一遍，改 `i18n.js` 里对应的那一列即可。

## 部署步骤

1. **注册小程序**：在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册小程序拿到 AppID，把 `project.config.json` 里的 `touristappid` 换成你的 AppID。
2. 用**微信开发者工具**打开 `miniapp/` 目录。
3. **开通云开发**：工具栏「云开发」→ 开通，记下环境 ID，填到 `miniprogram/app.js` 的 `ENV_ID`。
4. **建数据库集合**（云开发控制台 → 数据库），共 7 个：
   `users`、`clubs`、`members`、`events`、`signups`、`matches`、`ratingHistory`。
   权限都设为「**仅管理端可读写**」，所有读写都走云函数并在那里校验权限。
5. **建索引**（数据量大了以后查询更快，可以后加）：
   - `members`: `userId`、`clubId`
   - `events`: `clubId + startTime`
   - `signups`: `eventId + status + createdAt`
   - `matches`: `eventId`、`clubId + status + playedAt`、`players + status + playedAt`
   - `ratingHistory`: `userId + at`、`matchId`
   - `clubs`: `inviteCode`
6. **部署云函数**：右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」。
7. 编译预览即可。头像会上传到云存储的 `avatars/` 目录。

## 网页交互预览

`preview/` 用小程序真实的评分、对阵、积分榜和多语言代码，生成一个可以在浏览器里点的预览页（带演示数据，不连云端）：

```
node miniapp/preview/build.js preview.html
```

适合在拿到 AppID 之前给球友看效果。改了算法或文案后重新运行一次即可同步。

## 测试

不需要微信环境，Node 18+ 即可：

```
cd miniapp/cloudfunctions/api
npm test
```

- `lib.test.js`：评分公式、收敛模拟、轮转公平性（8 人 7 轮搭档零重复、上场次数差 ≤ 1、不连续轮空）、循环赛、积分榜
- `flow.test.js`：用内存数据库跑完整业务：建俱乐部 → 邀请码加入 → 报名/候补/递补 → 生成对阵 → 录分 → 权限 → 改分/删局回滚 → 积分榜
- `pages.smoke.test.js`：用假的 `wx`/`Page` 全局直接跑页面 JS，点一遍主要流程；并验证语言自动识别、手动切换、错误提示翻译、日期格式和币种

测试覆盖不到 WXML 渲染和真机交互，上线前请在开发者工具和真机上过一遍。

## 已知限制 / 后续可做

- 改分、删局用的是「撤销该局的评分变化再重算」，不会重放之后的所有比赛，属于近似处理。
- 活动报名不收费，费用只做展示；可接微信支付或做 AA 记账。
- 可扩展：赛事（小组赛 + 淘汰赛）、King of the Court 模式、订阅消息提醒、活动签到、导出 Excel。
- 本评分是模拟实现，与 DUPR 官方无关联，仅供俱乐部内部参考。
