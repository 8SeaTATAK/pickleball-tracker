# Lobtrix 赛制说明（校对版）

> 整理：2026-11-28 · 用途：了解 House of Pickle（HOP）、Pickleball NSW 在 Lobtrix 上办赛的方式，作为我们小程序做赛事功能的参考。
>
> **每一条都标了来源，三类不要混用：**
> - 【平台】Lobtrix 的实际实现（2026-11-28 核对）
> - 【USAP】*2026 USA Pickleball Official Rulebook* 15.B.4 / 15.B.5 / 15.B.6
> - 【惯例】赛事常见做法，由主办方自己定

## 一、一场 HOP 赛事的流程

```
报名（按 DUPR 分档 + 性别组合）
   ↓
分组循环（Pool Play）：每组 3–5 队，组内互打
   ↓
按组内名次排种子
   ↓
淘汰赛（单败为主）
   ↓
决赛 → 金 / 银 / 铜牌
```

- 【USAP 15.B.5】「先循环、后淘汰」时，循环赛**只用来定种子**，名次由淘汰赛决定。
- 也有**纯循环**的组别，循环排名就是最终名次。
- 【平台】公开赛事页只在**赛事级**写一句赛制说明（例：分组循环进入淘汰赛，保底 3–4 场）。**每个组别具体用什么赛制，只有组织者后台看得到**，所以不确定就问 TD。

## 二、报名与组别

| 项目 | 说明 |
|---|---|
| 分档 | 主要按 DUPR，常见 2.0–2.9 / 3.0–3.49 / 3.5+ |
| 性别组合 | 男双、女双、混双分开设组 |
| 一人多组 | 可以报多个组别，系统按 DUPR 区间校验资格 |
| 找搭档 | 可发邀请；可各付一半，或替搭档付 |
| 候补 | 满员自动进候补，有人退出自动递补并通知 |
| 平台费【平台】 | **每人每个组别 US$3**（条款原文：per player per division entered），报两个组收两次；以美元计价；Player Plus 会员免；组织者端目前免费；看对阵和成绩免费 |
| 报名费【实测】 | HOP 及同类赛事 **A$20–A$50**（例：万圣节社交赛 A$20，Tour de Cure 慈善赛 A$50） |

## 三、赛制：其实分四个层级

原稿说「Lobtrix 支持 5 种赛制」，实际上是不同层级的东西：

| 层级 | 选项【平台】 | 说明 |
|---|---|---|
| **组别赛制** | 纯循环 `round_robin` | 组内互打，按排名定名次 |
| | 循环 + 决赛 `round_robin_playoffs` | 循环后，前几名进决赛阶段 |
| | 分池 → 单败 `pool_play_se` | 先分组循环，出线者打单败淘汰 |
| | 单败 `single_elim` | 直接淘汰 |
| **赛事级** | 双败 `double_elim` | 胜者组 + 败者组 |
| **未上线** | 瑞士轮 Swiss | 后台标「Coming soon」，**目前选不到** |
| **搭档方式** | 固定搭档 `fixed` / 每轮换搭档 `scramble` | Scramble 不是赛制，是搭档方式，个人积分累计；联赛另有 scramble 赛季模式 |
| **联赛机制** | 阶梯 Ladder | 不是赛事赛制，是联赛的**周赛积分榜**（league_points + 季后赛周），赛事里选不到 |

- 赛制**按组别分别设**：同一赛事里，3.0 组可能是循环 + 淘汰，2.0 组可能是纯循环。
- 对阵表自动生成；现场改对阵（迟到、退赛）不会丢已录的比分。

## 四、循环赛排名

### 4.1 第一步：比胜场【USAP 15.B.4】
按**赢下的比赛场数**（matches won）排，不是局数，也不是总得分。

### 4.2 胜场相同：两套顺序，别混

**USA Pickleball 规则**（很多澳洲赛事的基准），逐级判定，分出来就停：

| 级 | 依据 | 说明 |
|---|---|---|
| ① | 相互战绩 | 平局者之间谁赢过谁 |
| ② | 总净胜分（所有比赛、所有局） | 多池且各池人数不等时不适用 |
| ③ | 相互净胜分 | 只看平局者之间的比赛 |
| ④ | 对上一名的净胜分 | 对排在更高一位的那队 |
| ⑤ | 总得分 | 多池人数不等时不适用 |

五级用完仍平局，由赛事总监裁定。

**Lobtrix【平台】**：顺序由组织者配置，是一个可排序的列表。

- **默认**：胜场 → 相互战绩 → 净胜分 → **失分最少**。
- **跟 USAP 的差别**：第 4 级不同（USAP 是相互净胜分，Lobtrix 是失分最少）；Lobtrix 默认没有「总得分」这一级。
- **可选项共 15 个**，包括：胜率、相互战绩、多队平局小联赛（只看平局者之间的成绩）、相互净胜分、局差、胜局数、总得分、总失分、负场最少、附加分、弃权最少、对手强度、抽签等。

所以只能说「USAP 这么排；Lobtrix 可以配，默认是这四条」，不能说「Lobtrix 就是这么排的」。

### 4.3 净胜分按局累加【USAP】
> A 队第一场 11-8、11-4 赢 → 净胜分 +10（+3 和 +7）
> 第二场 11-9、2-11、11-6 → −2（+2、−9、+5）
> 合计 +8

三局两胜里输掉的那一局也算净胜分。2-11 输一局和 9-11 输一局，伤害差很多。

### 4.4 算例：第三级才分出来
A、B、C 单循环，都是 1 胜 1 负：A 胜 B 11-7，C 胜 A 11-9，B 胜 C 11-5。

1. 相互战绩：A>B>C>A 循环，分不出。
2. 总净胜分：A +4−2=**+2**，B −4+6=**+2**，C +2−6=**−4** → C 第 3。
3. 相互净胜分（A vs B）：A +4，B −4 → **A 第 1，B 第 2**。

（按 Lobtrix 默认链，C 同样在净胜分这一级被分出来。剩下 A、B 怎么分，取决于系统是**从头再比**还是**接着往下比**：从头再比，相互战绩 A 胜 B → A 第 1；接着往下比，下一级是「失分最少」：A 失 7+11=18，B 失 11+5=16 → **B 第 1**。Lobtrix 用哪种处理方式**还没核实**。同一组比分可能排出不同结果，所以一定要问清楚用哪套规则；我们自己做的时候也要明确规定。）

### 4.5 退赛 / 弃权
- 【USAP 15.B.4.a】有人退赛、伤退或弃权：其**所有比赛成绩不计入**组内排名；失去淘汰赛和奖牌赛资格；已经打完的比赛**仍计入 DUPR**。
- 【平台】记录弃权原因、弃权方和比赛结果，弃权可设为计 0 或 1 分；**整组成绩是否作废，是赛事设置，平台不强制**。

## 五、淘汰赛与奖牌

| 项目 | 说明 |
|---|---|
| 单败 | 输一场出局 |
| 双败【平台：赛事级】 | 输一场进败者组，输两场出局。决赛常见做法：败者组上来的队要连赢两场才夺冠【惯例】 |
| **出线名额**【平台】 | **每个组别单独设**，不是固定前 2。实例：女双 2.0–2.9 取 4（→半决赛）；女双 3.0–3.49 取 2（→直接决赛）；混双 2.0–2.9 三个池共取 4（→四分之一决赛 → 半决赛 → 决赛） |
| **奖牌轮**【平台】 | 金、银、铜可以分别开关；铜牌赛由两个半决赛败者对打 |

## 六、计分与赛程

| 项目 | 说明 |
|---|---|
| 局 | 11 分（领先 2 分），也有 15、21 分 |
| 场 | 1 局定胜负，或三局两胜（best of 3） |
| 计分方式 | 发球得分制（traditional / side-out）或直接得分制（rally）；常见预设：11 分领先 2 分，直接得分 15 分 |
| 赛程参数【平台】 | 保底场次（例中每组 3–6 场不等）、每场时长、换场时间、休息时间、可用场地数、同时开打或依次进行 |
| 队伍规模【平台】 | 单打 1 人、双打 2 人，还支持 4 人团队赛；联赛有「一场团体赛（tie）+ 若干盘（rubber）」两层结构 |

计分方式影响净胜分：直接得分制分差更均匀；发球得分制连续得分会拉大分差。

## 七、联赛与积分

- 【平台】联赛积分 = 胜场 × 每胜积分（可设 1 / 2 / 3；实例 31 胜 = 62 分）。
- 可设「去掉最差一周」；中途加入按已打周数折算（可加入到第 N 周）。
- **没有跨赛事的巡回积分**【平台】：没有系列赛 / 巡回赛的数据结构。Lobtrix 上只有「单场赛事名次」「联赛积分榜」和 DUPR 三种成绩。

## 八、比赛当天

签到表 → 实时对阵表（几号场、几点）→ 场边任何手机都能录分，排名自动重算 → 实时排名 → 赛后成绩同步 DUPR（如果是 DUPR 计分赛）。HOP 的赛事主要在 Lobtrix 上办。

## 九、给球员的建议

1. 每局都认真打完：三局两胜已经 1-0 领先时，输的那局也算净胜分。
2. 先问清楚本组是「循环定名次」还是「循环定种子」，以及平局用哪套规则。
3. 尽量别弃权：按 USAP 规则会失去奖牌资格，成绩可能整组作废（看赛事设置）。
4. 同组有人退赛，问 TD 排名怎么重算。
5. 报多个组别要留体力，HOP 一天赛程可能是 07:00–17:00。
6. 不确定就问 TD 或 hello@lobtrix.com：公开页只写赛事级赛制，组别赛制要问。
