# Pickleball Tracker

Live availability tracker for pickleball courts at Tennis World North Ryde, auto-refreshed
every 30 minutes by GitHub Actions — no local machine needs to stay on.

- **Page**: served by GitHub Pages from this repo (Settings → Pages → deploy from `main` / root).
  Works on desktop (16 × 8 grid) and on phones (date strip + one court per row), and can be
  added to the home screen as an app.
- **Data**: `data/availability.json` is regenerated by `scrape.mjs`, run on a schedule by
  `.github/workflows/refresh.yml`. Trigger a refresh by hand from the Actions tab →
  *Refresh pickleball availability* → **Run workflow**.
- **My bookings**: `data/mine.json` — edit this file directly (GitHub web UI or mobile app) to
  mark a court/date/time slot as booked; it shows green on the page. Entries for past dates are
  moved to `data/history.json` on the next scrape.
- **Stats**: `data/history.json` is the archive of past bookings behind the "我的订场统计"
  section at the bottom of the page. Nothing writes to it except the scrape step.

## Files

| File | Purpose |
|---|---|
| `index.html` | the whole page — desktop grid, phone layout, stats, no build step |
| `scrape.mjs` | fetches the MindBody RSC payload per court, writes `data/availability.json` |
| `manifest.json`, `sw.js`, `icon-*.png` | home-screen install; the worker is network-first, so a phone with signal always sees fresh data and one without still opens the page |
| `AGENTS.md`, `CLAUDE.md` | maintenance rules for AI assistants (Chinese) |
| `docs/OPERATIONS.md` | full operations guide: every module, online / local / cloud setups, troubleshooting (Chinese) |
| `scripts/windows/` | `setup-sync.bat` keeps a local copy synced every 30 min; `open-page.bat` serves it at localhost:8000 |

## Local run

```
node scrape.mjs
```

Requires Node 18+ (uses the built-in `fetch`).

## Recording a booking from a phone

The page is read-only for everyone by default. To turn one device into an
editor:

1. On GitHub, create a **fine-grained personal access token**: *Settings →
   Developer settings → Personal access tokens → Fine-grained tokens*. Scope it
   to **this repository only**, with **Repository permissions → Contents:
   Read and write** and **Actions: Read and write** (the second one powers the
   refresh button). Nothing else.
2. On the phone, open `https://8seatatak.github.io/pickleball-tracker/#edit`
   and paste the token when prompted.

From then on that device shows an **✎ 编辑我的预订** button. Tap slots to toggle
them, then **保存到 GitHub** — it commits `data/mine.json` through the contents
API, and Pages redeploys in about a minute.

## Refreshing from the source on demand

The **↻ 从源站刷新** button at the top of the page (shown on any device that has a
token) starts the *Refresh pickleball availability* workflow, waits for the scrape
to finish (usually under a minute), then reads the new files straight from the repo
through the API — no waiting for Pages. MindBody sends no CORS headers, so the
browser can't scrape it directly; the workflow does it instead. Without a token the
button just reloads the latest published data.

The token lives only in that browser's `localStorage`; it is never committed and
never leaves the device except as an `Authorization` header to api.github.com.
Open `#forget` to wipe it from a device, or revoke it on GitHub if a phone is
lost.
