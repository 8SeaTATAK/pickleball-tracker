# Pickleball Tracker

Live availability tracker for pickleball courts at Tennis World North Ryde, auto-refreshed
every 30 minutes by GitHub Actions — no local machine needs to stay on.

- **Page**: served by GitHub Pages from this repo (Settings → Pages → deploy from `main` / root).
- **Data**: `data/availability.json` is regenerated by `scrape.mjs`, run on a schedule by
  `.github/workflows/refresh.yml`.
- **My bookings**: `data/mine.json` — edit this file directly (GitHub web UI or mobile app) to
  mark a court/date/time slot as booked; it shows green on the page. Entries for past dates are
  pruned automatically on the next scrape.

## Local run

```
node scrape.mjs
```

Requires Node 18+ (uses the built-in `fetch`).
